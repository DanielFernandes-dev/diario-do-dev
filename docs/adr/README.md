# ADR Log

Registro de decisões arquiteturais do projeto.

## Como usar

- Cada ADR deve ficar em um arquivo numerado.
- Use o formato `0001-nome-da-decisao.md`.
- Atualize este índice quando uma nova decisão relevante for registrada.
